# Challenge 09 - Finding the nth Triangular Number
In this challenge, you are going to implement the `TriangularNumbers` function which takes in `n` and returns the `nth` [triangular number](https://en.wikipedia.org/wiki/Triangular_number).

```
n = 1
result = 1

n = 3
result = 6
```

The Triangular number for any given number `n`, can be calculated applying the expression:
$$ T_n = \sum_{k=1}^n 1 + 2 + ... + n$$
simplified as
$$ T_n = [n (n + 1)] / 2$$
