# Challenge 14 - Smallest Difference between Ints
👋 Welcome Gophers! In this challenge, you are tasked with finding the smallest difference between two slices of `int` values.

## Example
Let’s say I have 2 int arrays; `A = [2, 1]` and `B = [4, 5]`. The function should return the smallest difference which would be the difference between 4 and 2:

| A | B | Diff |
|:-:|:-:|:----:|
| 1 | 4 | 3 |
| 1 | 5 | 4 |
| 2 | 4 | 2 |
| 2 | 5 | 3 |
